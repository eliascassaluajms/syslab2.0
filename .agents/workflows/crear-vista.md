---
description: Crea una nueva vista en `frontend/src/views/` para el sistema SysLab 2.0 siguiendo esta estructura:
---


1. Define las interfaces TypeScript necesarias en `frontend/src/interfaces/`.
2. Crea el servicio HTTP correspondiente en `frontend/src/services/` con manejo de errores `try/catch`.
3. Construye el componente de la vista en React usando TailwindCSS (estética en tonos oscuros `slate-900` / `slate-800`).
4. Incluye estados de carga (`loading`) y avisos de error en español.
